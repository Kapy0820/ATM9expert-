# Research logs — AIエージェントの検索作業記録

このディレクトリは **AIエージェントが「どこを、どの順番で、何を検索し、どう判断したか」を後から再現できる形で残す場所** です。完成したクラフト手順は `examples/`、一般的な調査手順は `docs/RESEARCH_PROTOCOL.md` に保存してください。

**まず** [TEMPLATE.md](TEMPLATE.md) をコピーして新規ログを作成してください。検索を始める前に関連する過去ログを確認し、同じ検索を無駄に繰り返さないでください。

## 保存のルール

- ファイル名: `YYYY-MM-DD_<namespace>_<item>_<agent-or-run>.md`（例: `2026-11-08_mekanism_metallurgic_infuser_agent-a.md`）。識別子は小文字英数字、`-`、`_` のみ。
- 複数エージェントが同じアイテムを調べた場合は **別ファイル** にする。既存の他エージェントのログを上書きしない。
- ログには **実際に試した** 検索クエリ、取得URL、対象リポジトリ、固定コミット/ブランチ、対象ファイルと行、発見事項、失敗した検索、判断理由、次の調査先を記録。
- **検索日時と参照コミットを分離** する。古いソースでも、調べた日時は最新であり得る。
- ソースを開かなかった、バージョンを照合しなかった、実ゲームで確認していないことは必ず明記する。
- 「検索結果がなかった」だけで「レシピは存在しない」と決めない。調べた範囲も示す。
- 非公開トークン・Cookie・個人情報・無関係の大量のログ・著作権のある長文ソースは保存しない。公開ソースは **URLと要約** を残す。
- 処理中のログは「進行中」と記入し、回答後に「完了（部分的）」「完了（直接レシピ）」「中断／未解決」のいずれかで締める。

## 何をどこへ残すか

| 保存先 | 内容 |
| --- | --- |
| `research-logs/YYYY-MM-DD_....md` | 検索語・検索順・候補ファイル・成功と失敗・推論・次の手 |
| `examples/<namespace>_<item>.md` | プレイヤーが読める完成版のレシピ調査結果（範囲を明示） |
| `examples/<namespace>_<item>.json` | 製作レシピの構造化データ（必要に応じて） |
| `AGENTS.md` / `docs/` | すべてのエージェントが再利用する共通方針 |
